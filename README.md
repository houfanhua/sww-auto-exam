# 双卫网智能答题助手

> 针对 [双卫网](https://www.sww.com.cn/)（继续医学教育平台）的 Tampermonkey 用户脚本：**自动答题** + **自动刷课** 两个独立模式。

## 一键安装

👉 **[点这里安装脚本](https://raw.githubusercontent.com/houfanhua/sww-auto-exam/main/sww-auto-exam.user.js)**

Tampermonkey 会自动弹出安装页，点「安装」即可。之后脚本会自动跟随本仓库更新（`@updateURL` 已配置）。

> ⚠️ **如果你之前装过桌面上那份 `双卫网自动答题.user.js`，请先在油猴管理面板里把它删掉再装这个**，否则两个脚本同时运行会互相抢答、日志翻倍。

前置条件：

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox 均可）
2. 打开 Tampermonkey 设置 → 通用 → 允许访问文件网址（可选，一般不需要）
3. 登录双卫网后打开任意课程页，左下角会出现脚本工具条

## 功能

### 一、答题模式

| 能力 | 说明 |
|---|---|
| 题目识别 | 按站点真实结构解析（`.online-dati-title` 题干 + 各题选项组），支持单选 / 多选 / 判断 |
| 三级取答 | ① 本地题库（答对过的题，★★★★★）→ ② 大模型（OpenAI 兼容接口）→ ③ 联网搜题（360 / 搜狗 / 必应 / 百度并行） |
| 答错重答 | 自动拦截站点的错误 `confirm` 弹窗、解析错题号、换候选答案重答，直到通过（默认最多 12 轮） |
| 答案沉淀 | 全部答对后，本轮答案自动入库，下次同题直接命中 |
| 手动兜底 | 「记录答案」可把当前手动勾选的结果存入题库 |

### 二、刷课模式

| 能力 | 说明 |
|---|---|
| 自动串课 | 进未学完课时 → 播放 → 播完回课程列表 → 找下一节，循环到整门课结束 |
| 在线确认 | 自动处理播到 10 分钟时弹出的「您是否在线」表单弹窗（勾选 A、点提交、自动续播） |
| 以站点为准 | 回课程列表核对是否变成「视频（已学）」；没记上就重进补学，**绝不自己给自己发毕业证** |
| 不阻塞 | 某节核对 2 次仍失败 → 记入跳过名单继续学后面的，收尾统一汇报 |
| 断点续播保护 | 一进课时就在结尾（站点记忆位置）会自动拉回开头重播，避免「假学完」 |
| 诊断 | 每分钟一行 `[自检]`、一键「复制日志」，排障不用截图 |

## 使用

### 工具条按钮

| 按钮 | 作用 |
|---|---|
| **识别** | 只解析当前答题页的题目结构，不作答（确认脚本认不认得出题） |
| **仅勾选** | 只勾答案不交卷（推荐，自己点交卷） |
| **填答并交卷** | 勾选并自动交卷 |
| **记录答案** | 把当前手动勾选的答案存入题库 |
| **识别课时** | 列出课程页识别到的课时链接与状态（刷课诊断用） |
| **自动巡航** | 开始自动刷课：进未学完课时 → 处理弹窗 → 播完跳下一节 |
| **停巡航** | 停止自动刷课 |
| **强制学完** | 视频卡住 / 读不到进度时，手动判定本节完成并推进 |
| **清已学记录** | 清空「已进过的课时」记录（想强制重学全部课时时用） |
| **巡航状态** | 打印当前页面角色、视频进度、弹窗状态（排障用） |
| **复制日志** | 把完整日志 + 状态 JSON 复制到剪贴板 |
| **重置** | 清除本地进度与题库 |

### 快捷键（答题页）

| 快捷键 | 作用 |
|---|---|
| `Alt + A` | 填答并交卷 |
| `Alt + B` | 只勾选，不交卷 |
| `Ctrl + Enter` | 交卷 |

### 刷课推荐流程

1. 打开**课程详情页**（URL 形如 `/html/projectDetail?project_id=...`）
2. 点「识别课时」——日志里应能看到若干「视频（未学）」，说明识别正常
3. 点「自动巡航」，然后就可以不管它了
4. 每节视频会**完整播完**才跳下一节（40 分钟的课就是 40 分钟），中途 10 分钟的「您是否在线」会自动处理

> 注意：**请在课程详情页点「自动巡航」，不要在播放页点**。v4.5 起脚本会自己换算巡航起点，但详情页启动最稳。

## 配置

配置存放在油猴存储（`sww_auto_exam_cfg_v3`），也可以在脚本源码的 `DEFAULTS` 里改默认值：

| 键 | 默认 | 说明 |
|---|---|---|
| `strategy` | `auto` | 取答策略：`auto` 三级兜底 / `bank` 只用题库 / `ai` 只用大模型 / `search` 只联网搜 |
| `autoSubmit` | `false` | 打开答题页是否自动交卷 |
| `autoRetry` | `true` | 答错后自动换答案重答 |
| `maxRetry` | `10` | 单题最多尝试多少个候选答案 |
| `maxRounds` | `12` | 最多自动重答轮数 |
| `searchEngine` | `both` | 搜题引擎：`all` / `so360` / `sogou` / `bing` / `baidu` |
| `aiEndpoint` / `aiKey` / `aiModel` | 空 | OpenAI 兼容接口，填了就优先用大模型 |
| `playbackRate` | `1` | 视频倍速（站点若会重置倍速则无效，属正常） |
| `lessonMaxMin` | `45` | 单课时最长停留分钟数（读不到视频时长时的兜底上限） |
| `skipEntered` | `true` | 脚本进过的课时不再重复进（防浪费时间） |
| `restartIfNearEnd` | `true` | 从结尾续播时拉回开头重播 |
| `debug` | `false` | 控制台详细日志 |

> 🔒 大模型 Key 只保存在你本机的油猴存储里，不会上传到任何第三方；本仓库不包含任何密钥。

## 工作原理

（以下机制来自对站点 `study_video.min.js` 的逆向阅读 + 实际播放验证）

1. **播放器是页面内的 `<video>`**（阿里云播放器），不是跨域 iframe —— 所以脚本能直接读到 `currentTime` / `duration`。
2. **每播满 10 分钟，站点强制暂停并弹出「您是否在线」表单弹窗**（`.dati-dialog` + checkbox + 提交按钮）。不答，视频永远停在那里。
3. **播到剩最后约 20 秒时，站点自己调用 `member/logStudy` 上报 `is_complete=1`** —— 不是等 `ended` 才记。
4. **服务端按真实播放秒数校验**：播放器禁拖动（`video_can_drag=0`）、倍速会被重置；真实时长不够会返回「学习时长检测异常，不记录」。
5. **播放位置存在 localStorage**（key 形如 `会员号_课时id_项目id`）。如果残留位置在结尾附近，每次进来都从结尾续播 → 真实秒数永远不够 → 死循环。

由此推出的两条硬规则，也是本脚本的核心设计：

- **只有在真正播到最后一刻（`ended` 或距结尾 1 秒内）才算学完**。任何"接近完成"的提前跳转都会让站点判定时长不足，整条链路变成假成功。
- **是否学完以站点状态为准**：回课程列表看它是「视频（已学）」还是「视频（未学）」，不看脚本自己数了几节。

## 常见问题

**Q：装完没反应，左下角没有工具条？**
确认 URL 是 `sww.com.cn` 域名、油猴里脚本已启用、并且**只装了一个**版本（旧版要先删）。

**Q：为什么一节课要等 40 分钟，不能加速？**
站点服务端校验真实播放秒数，加速或拖动都会被判"时长异常"而不记学时。脚本不提供加速就是这个原因。

**Q：日志说「试了 3 次站点都没记成已学」？**
说明脚本判完跳走了但站点没认。处理顺序：
1. 手动把这节完整看一遍，看列表是否立刻变「已学」；
2. 点「复制日志」把 `[自检]` 行和状态 JSON 发到 [Issues](https://github.com/houfanhua/sww-auto-exam/issues)；
3. 临时绕过：点「清已学记录」再点「自动巡航」，会重新尝试之前跳过的课。

**Q：中途弹出人脸认证？**
本项目实际不触发人脸认证，只有「您是否在线」在线确认。脚本对身份认证类弹窗**只提醒、绝不代点**，需要你本人操作。

**Q：答题搜不到怎么办？**
按 `本地题库 → 大模型 → 联网搜题` 的顺序试。医学继续教育题在 360 搜索命中率最高。也可以自己勾选后点「记录答案」入库。

**Q：换电脑了，题库会丢吗？**
题库存在油猴存储里。用 Tampermonkey 自带的「导出/备份」功能，或本仓库的 `@updateURL` 机制都只同步脚本、不同步数据，需要手动导出。
